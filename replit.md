# PPT to PDF Converter - Project Documentation

## Project Overview
A modern web application that converts PowerPoint and Word documents to PDF format with batch processing capabilities, real-time progress tracking, and a user-friendly interface.

## Current Architecture
- **Frontend**: React with Vite, TypeScript, Tailwind CSS, shadcn/ui components
- **Backend**: Express.js with file upload and conversion capabilities
- **Storage**: In-memory storage for file management
- **Routing**: Wouter for client-side routing
- **State Management**: TanStack Query for server state

## Current Features
- PowerPoint (.ppt, .pptx) and Word (.doc, .docx) to PDF conversion
- Batch file processing (up to 10 files, 100MB each)
- Real-time conversion progress tracking
- Individual and bulk download options
- Responsive design with color-coded file type icons
- Automatic file cleanup after 24 hours
